# Cloud Deployer — документация продукта

> о том, что мы строим и почему.

## Что это за продукт (в одном абзаце)

Self-hosted PaaS — «мини-Kubernetes для малого бизнеса». Продукт ставится на
сервер **одной командой**, поднимает себя и инфраструктуру (reverse-proxy,
выпуск SSL) и даёт владельцу **веб-UI**, через который он заливает приложение
(ZIP/репозиторий), привязывает домен и получает работающий сервис с HTTPS —
без DevOps-инженера. Ядро держит сервисы живыми по принципу «желаемого
состояния»: сказано «нужно N реплик» — система поддерживает N.

## Бизнес-смысл

Сократить расходы малого и мало-среднего бизнеса на деплой: вместо найма
DevOps или аренды managed-платформы — один дешёвый VPS и наш продукт.
Опора: **безопасность, надёжность, для MVP — простота**.

## Cloud-издание

Над OSS-ядром надстроено **cloud-издание** — личный кабинет с ИИ-студией и
маркетом компонентов: платформа провизионит сервер клиента, DNS и HTTPS
одним окном, агент строит приложение в изолированном workspace, публикация —
на ноду пользователя. Cloud-код приватный и в публичный срез не входит.

1. Доки — про «почему» и «куда», код — про «как».
2. Язык документов — русский (язык команды).
3. Пометка достоверности для цифр: **[ФАКТ]** (код, прайс, счёт), **[ОЦЕНКА]**,
   **[ГИПОТЕЗА]**. Нет данных — так и пишем.

## Текущий статус одной строкой

**MVP в работе.** Ядро стабилизировано, стек контейнеризован
(`docker compose up -d --build`), one-command install (`install.sh`/`install.ps1`)
с авто-онбордингом админа, тесты (pytest). Установка одной командой проверена
на чистом Debian 11 (панель по HTTPS с Let's Encrypt). Установка и первый
деплой — [`07_DEPLOY.md`](07_DEPLOY.md).
